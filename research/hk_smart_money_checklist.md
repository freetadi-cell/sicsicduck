# 大戶動能交易清單 Checklist

每朝開市前用呢張紙掃一次，唔符合就唔好手痕。

---

## □ 第一步：市場環境

- [ ] 恒指企穩 20MA 以上？（或至少唔係連續破底）
- [ ] 市場成交額唔低於 20 日均量？
- [ ] 板塊輪動正常，唔係只靠一兩個板塊撑？

> 以上全部 Yes → 可以正常操作  
> 有任一 No → 減半注碼或觀望

---

## □ 第二步：揀板塊

- [ ] 有板塊連續 3 日以上資金淨流入？
- [ ] 板塊相對恒指強弱上升？
- [ ] 板塊內至少 3 隻股份同步轉強？
- [ ] 板塊成交量大於 20 日均量？
- [ ] 領漲股唔係無基本因素嘅細價股？

> 全部符合 → 列入「本日強勢板塊」  
> 符合 3 項 → 觀察名單  
> 符合少於 3 項 → 唔參與

---

## □ 第三步：揀股

- [ ] 屬於上述強勢板塊？
- [ ] 大單／超大單淨買比例上升？
- [ ] 價升量增、突破有量？
- [ ] 回調時明顯縮量？
- [ ] 企穩 20MA 或以上？
- [ ] 日均成交額夠流動？
- [ ] 未大升一段（唔追末段）？

> 符合 ≥ 5 項 → 優先名單  
> 符合 4 項 → 候補  
> 符合 ≤ 3 項 → 唔買

---

## □ 第四步：下單前

- [ ] 單一板塊唔超過 30–40%？
- [ ] 單一股票唔超過 10–15%？
- [ ] 已設好止蝕位？
- [ ] 已預計止賺位置？

---

## □ 第五步：收市後檢視

- [ ] 板塊資金流向有冇轉弱？
- [ ] 個股有冇出現大戶出貨跡象？
- [ ] 明日是否需要調整倉位？

---

## 記住口訣

1. 先睇錢去邊
2. 再睇勢對唔對
3. 再睇個股係咪領先
4. 要有量配合
5. 有懷疑就唔好追
